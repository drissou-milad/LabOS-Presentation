Documentation Principles

All visual materials should:

Represent genuine project development.

Include a short descriptive caption.

Avoid exposing private source code or confidential data.

Identify preliminary experiments as experimental.

Avoid implying scientific validation that has not yet been established.

Distinguish platform interface screenshots from scientific evaluation evidence.

The purpose of this directory is to make LabOS easier to understand and evaluate through transparent visual evidence.
