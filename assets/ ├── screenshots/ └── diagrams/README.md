# LabOS — Visual Documentation

This directory contains selected visual materials illustrating the development, architecture and experimental evaluation of LabOS.

## Screenshots

The `screenshots/` directory is intended to contain genuine screenshots of the LabOS software and its experimental workflows.

Potential materials include:

- Application interface.
- Microscopy image input.
- Cell detection examples.
- Cell tracking visualisations.
- Cell division examples.
- Reconstructed cell lineage visualisations.
- Experimental results and evaluation outputs.

Only screenshots from actual project executions should be included.

## Diagrams

The `diagrams/` directory contains visual explanations of the LabOS architecture and its main processing workflows.

## Documentation Principles

All visual materials should:

- Represent genuine project development.
- Include a short descriptive caption.
- Avoid exposing private source code or confidential data.
- Identify preliminary experiments as experimental.
- Avoid implying scientific validation that has not yet been established.

The purpose of this directory is to make LabOS easier to understand and evaluate through transparent visual evidence.
